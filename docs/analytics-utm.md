# Links de campanha — Instagram

Os links abaixo são os links oficiais que devem ser usados nas divulgações da ROOM no Instagram.

## 1. Site da ROOM

```text
https://www.roomarquiteturasustentavel.com.br/?utm_source=instagram&utm_medium=social&utm_campaign=perfil
```

Use este link quando o objetivo for levar a pessoa para a página principal da ROOM, especialmente na bio do Instagram.

## 2. Solicitação de orçamento/proposta

```text
https://www.roomarquiteturasustentavel.com.br/orcamento?utm_source=instagram&utm_medium=social&utm_campaign=orcamento
```

Use este link quando o objetivo da publicação for levar diretamente para a solicitação de proposta/orçamento.

## Convenção

- `utm_source=instagram` identifica o Instagram como origem.
- `utm_medium=social` identifica o tráfego como rede social.
- `utm_campaign=perfil` identifica o link geral do perfil/bio.
- `utm_campaign=orcamento` identifica o link direcionado à solicitação de proposta.

Não criar variações adicionais de UTM sem necessidade. Como o objetivo atual é acompanhar apenas esses dois caminhos, manter os nomes das campanhas padronizados evita fragmentar os dados no Google Analytics.
